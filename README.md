## The joke

> The office printer only jams when I'm already late, which is how I know it reads my calendar.

## How it works

`main.py` is a deterministic program that writes the one-line office joke above
to `/output/entry.txt`. Nothing else is written; the output is a single line of
under 200 characters. The program refuses to run if the joke ever falls outside
the 1–199 character gate.

Run it locally (the grader sandbox writes to `/output`):

```sh
python3 main.py
```
